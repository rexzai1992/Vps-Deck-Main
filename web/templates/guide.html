Log in & your dashboard

Where you land after signing in

Open your VPSDeck URL in a browser and sign in with your admin password. After login you land on the Dashboard, which shows a live snapshot of your server's CPU, memory, and disk usage alongside all registered projects.

  • 1
    Open VPSDeck Go to your panel URL, e.g. https://vps.example.com or http://<server-ip>:8080.
  • 2
    Enter your password Type the admin password you set when you installed VPSDeck and click Sign in.
  • 3
    Dashboard overview Four metric cards show CPU, memory, disk, and uptime. Below is your project list with a real-time running/stopped indicator.

Register a project

Tell VPSDeck about an app already on your server

A project is an app folder on your VPS. VPSDeck registers the folder so it can show status, manage files, and set up a domain without moving your app.

  • 1
    Go to Projects → Add project Click Projects in the sidebar, then the Add project button in the top right.
  • 2
    Fill in the details Enter the folder path (e.g. /var/www/myapp), a display name, the app type, and the port it listens on.
  • 3
    Click Register project VPSDeck saves the project. Its status dot turns green if the port is reachable, red if the process isn't running.
💡 Tip: You can also add a project from a GitHub repository. VPSDeck clones the repo into the managed apps folder, stores the branch and deploy mode, and lets you deploy with one click from the panel.

Deploy & manage files

Push new code and edit files without SSH

If a project is connected to GitHub, hit Deploy latest to pull the newest commit and restart the service — all in one click. No terminal needed.

  • 1
    Open the project Click the project name in the sidebar or the Projects list.
  • 2
    Deploy latest Click Deploy latest. VPSDeck fetches the branch, applies a fast-forward merge, optionally rebuilds Docker Compose, and logs the output under Deployment history.
  • 3
    Browse & edit files Click Files to browse the project folder. You can upload files, create folders, edit text files in the browser, and download zips.
  • 4
    Manage env variables Click Environment to view and edit the project's .env file. Changes are saved directly to disk.

Domains & Nginx routes

Connect a public hostname to your project

The Domains page lets you create Nginx reverse-proxy routes that map a public domain name to a project port. VPSDeck writes and manages the Nginx config for you.

  • 1
    Point DNS first In your domain registrar, add an A record pointing your hostname (e.g. app.example.com) to your VPS public IP. Wait a few minutes for propagation.
  • 2
    Add a managed route Go to Domains → expand Add managed route, enter the hostname, select your project, and click Create route.
  • 3
    Test & Apply Click Test to check the Nginx config syntax, then Apply to reload Nginx and make the route live.
  • 4
    Import an existing config (optional) If you already have Nginx configs on the server, the Existing Nginx Routes section shows them all. Click Import to track one in VPSDeck — it never modifies the original file.
🔒 SSL (HTTPS): Once the HTTP route is live, run sudo certbot --nginx -d app.example.com on the server. Certbot handles the certificate and updates Nginx automatically. VPSDeck will then show the cert expiry date in the Domains table.

VPS Doctor

Diagnose and fix common server problems

VPS Doctor runs a set of automated health checks across your server: CPU, memory, disk, Nginx, Docker, and your running projects. It highlights problems and suggests repair actions.

  • 1
    Go to VPS Doctor Click VPS Doctor in the sidebar under System.
  • 2
    Run Full Check Click Run Full Check. Results appear within seconds showing OK ✓, Warning ⚠, or Failed ✗ for each item.
  • 3
    Act on warnings High disk usage? Clear logs. Nginx down? Click Restart Nginx. A stopped project? Click Start next to it.

Keeping VPSDeck up to date

Apply panel updates in one click

VPSDeck can update itself. The Updates page shows the current version and whether a newer release is available. Applying an update rebuilds the binary, swaps it in, and restarts the panel. Your projects keep running throughout.

  • 1
    Open Updates Click Updates in the sidebar under System.
  • 2
    Check for a new version The page shows your current version and the latest available. If they differ, an Apply Update button appears.
  • 3
    Apply the update Click Apply Update. VPSDeck downloads the new binary, replaces itself, and restarts. The panel is back within a few seconds.
📋 Audit log: Every important action you take in VPSDeck is recorded in the Audit log, including deploys, route changes, and file edits. If something goes wrong, check here first to see exactly what changed and when.
